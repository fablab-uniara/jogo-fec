# Validação da publicação

A hospedagem escolhida foi o GitHub Pages, no repositório público `fablab-uniara/jogo-fec`.

URL pública do jogo: https://fablab-uniara.github.io/jogo-fec/

URL pública do perfil: https://fablab-uniara.github.io/jogo-fec/perfil.html

O GitHub Pages informou `status: built` após a publicação e mantém HTTPS obrigatório. A página pública carregou a identidade CRISIS/UNIARA, o botão `ACEITAR O DESAFIO`, o comunicado inicial da diretoria e o painel de status.

Uma rodada foi iniciada diretamente no endereço público. O primeiro cenário carregou com as métricas, cronômetro, status `OPERAÇÃO INSTÁVEL`, decisões e alerta `COMUNICADO DA DIRETORIA` visíveis.
